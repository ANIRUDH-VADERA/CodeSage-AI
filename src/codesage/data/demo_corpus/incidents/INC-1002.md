# INC-1002 Ledger writer lost messages after a crash

## Summary
LedgerWriter committed Kafka offsets before the Postgres write finished. When a pod was killed
mid-batch, those messages were marked consumed but never written.

## Fix
Commit offsets only after the batch is written, and make the write idempotent with
`ON CONFLICT (event_id) DO NOTHING` so replays are safe.
